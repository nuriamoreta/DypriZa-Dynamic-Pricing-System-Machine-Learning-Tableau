## 📁 Source Code (src)

Esta carpeta contiene la estructura de código del proyecto DyPriZa.

El desarrollo principal del proyecto se ha realizado en notebooks de Jupyter, donde se incluyen:
- Análisis exploratorio de datos (EDA)
- Limpieza y preprocesamiento
- Modelos de machine learning
- Evaluación de resultados

En este proyecto, los notebooks representan el flujo completo de trabajo en lugar de scripts separados.
