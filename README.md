# DypriZa-Dynamic-Pricing-System-using-Machine-Learning-Tableau-
DyPriZa es un proyecto de dynamic pricing aplicado a alojamientos turísticos, donde se utilizan técnicas de machine learning para estimar precios óptimos en función de demanda, estacionalidad y mercado, complementado con dashboards en Tableau para apoyar la toma de decisiones basada en datos.
