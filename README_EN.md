# DyPriZa - Dynamic Pricing Machine Learning Project

## 📌 Project Description
DyPriZa is a dynamic pricing project applied to the short-term rental market. The objective is to estimate optimal prices using machine learning techniques based on demand, seasonality, and market behavior. The project combines data analysis, predictive modeling, and Tableau dashboards to support data-driven decision making.

## 🎯 Objective
To develop a predictive model that helps optimize pricing strategies and improve revenue management decisions.

## 🧠 Methodology
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature engineering
- Machine Learning models for price prediction
- Model evaluation and insights extraction
- Tableau visualization

## 📊 Project Phases

The project has been developed in the following stages:

- **01 EDA (Exploratory Data Analysis)**  
  Data exploration to understand distributions, key variables, and pricing behavior patterns.

- **02 Data Cleaning & Preprocessing**  
  Handling missing values, cleaning data, and preparing the dataset for modeling.

- **03 Feature Engineering**  
  Creating relevant variables to improve model performance.

- **04 Machine Learning Model**  
  Training models to predict optimal prices.

- **05 Evaluation & Insights**  
  Model evaluation and business insights extraction.

## 📁 Project Structure

- `notebooks/` → Exploratory analysis and experimentation
- `src/` → Source code (models and processing)
- `data/` → Project datasets
- `dashboards/` → Tableau visualizations

## 📁 Data folder

This folder is intentionally empty because the dataset used in this project is private and cannot be shared due to data privacy restrictions.

The project was developed using real-world data from the short-term rental market.
